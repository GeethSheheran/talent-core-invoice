Promise-based concurrent calls test retry outcomes; they do **not** prove real multi-connection lock behavior. 2. Auth/Storage platform schemas in the integration fixture are minimal. Hosted GoTrue session refresh, password recovery email, real Storage policy behavior and signed downloads need a configured development Supabase project. Supabase security advisors could not run without that stack.

## Operational scope

One issuing business; approved administrators only; supported two-decimal currencies; manual bank/cash/other payments. Credit corrections are fully applied to the originating invoice; transferable credit-note balances and automated refunds are not part of v1. Statements are current read-only reports.
